# 帧析 · 视频处理工具 Demo

本地 Python + Qt 客户端，提供**帧标记与导出、视频剪辑、视频格式转换**三个独立页面。

## 启动

在项目根目录执行 `python main.py`，或双击 `启动Demo.cmd`。当前电脑已验证 `D:\Anaconda3\python.exe` 可运行。

新环境可使用独立虚拟环境：

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

复用 PyQt5、OpenCV、NumPy、标准库 SQLite 和 FFmpeg。Excel 导出已移除，不再依赖 openpyxl。

FFmpeg 查找顺序：`FFMPEG_EXE`、PATH、`imageio-ffmpeg`、`.local/ffmpeg-path.txt`。当前电脑的 FFmpeg 路径已记录于该本地文件，不纳入 Git。

## 帧标记与导出

1. 点击“导入视频”，或“载入演示视频”生成六秒本地示例。
2. 播放/暂停、上一帧/下一帧，或输入帧编号跳转。帧号从 0 开始。
3. 勾选“标记当前帧用于导出”，也可按 M；取消勾选即可取消标记。
4. 右侧列出已标记帧，双击定位，可选中条目后取消标记。
5. 选择 PNG 或 JPG，点击“导出当前视频已标记帧”，只保存明确标记的帧。
6. 重启后点击“恢复上次任务”继续；标记和查看位置自动保存于 `.demo-data/frames.sqlite3`。

页面采用单画面显示，不导入检测 JSON、不绘制额外检测框或分割结果。视频本身已绘制的内容原样保留，导出图片保持原分辨率。

### 帧图片亮度审查

暂停并加载画面后可开启“亮度审查”。指针在画面同一位置停留 0.2 秒，浮动提示显示原图像素坐标（从 0 开始）及亮度 0–255。数值取自原始解码画面，以 `0.299R + 0.587G + 0.114B` 四舍五入计算，是 RGB 加权灰度值，不是物理亮度。缩放和平移不改变采样来源，黑边不采样。

播放时不可开启；开始播放、切换帧或视频会关闭审查并清除提示，暂停后需重新开启。移动指针重新计时，离开画面、拖动或缩放时清除旧提示。该功能不修改图片或导出内容。

已移除审核状态、问题分类、问题备注、批量审核、检测统计、分析表格导出和左右对照。旧版 `.demo-data/review.sqlite3` 保留在磁盘，本版不再读取；新标记独立保存，不清空旧数据。

### 限制与交互

- 当前列表最多十个视频，单个不超过三分钟，最高 2560×1440 或对应竖屏。
- 输入格式：MP4、MKV、AVI、MOV、WebM、M4V；实际可读性取决于本地解码器。
- 查看位置按解码帧序号定位；时间使用帧号除以 FPS，可变帧率的精确时间戳尚未实现。
- 帧缓存上限约 48 MiB，反向跳转未命中缓存时从头解码，较长视频随机跳转可能较慢。
- 后台读取和导出；视频浏览不播放音频，负载高时播放可能慢于原速。
- 每次导出新建时间戳子目录，文件名为 `frame_000055.png` 等，拒绝覆盖已有图片。
- 左右方向键逐帧、空格播放/暂停、M 标记/取消；滚轮缩放、拖动平移、双击复位。

## 视频剪辑与转换

- 剪辑：截取一个时间区间，起点包含、终点不包含，以秒输入，保存为新视频。
- 转换：输出 MP4、MKV 或 AVI，每次处理一个视频。
- MP4/MKV 使用 H.264 + AAC，AVI 使用 MPEG-4 + MP3；保留首条视频流和可选首条音轨。
- 重新编码，奇数宽高补齐至偶数；不承诺无损转换。
- 提供进度和取消，临时文件验证成功后才转为目标文件，拒绝覆盖源文件和已有输出。
- 不套用帧标记页面的三分钟、2K 限制。
- 暂不支持拼接、多区间删除、批量转换、参数调节、字幕或多音轨保留。

## 模块组织

| 文件 | 职责 |
| --- | --- |
| `main.py` | 启动入口 |
| `media_tool/ui.py` | 主窗口、剪辑及转换页面 |
| `media_tool/frame_page.py` | 帧定位、标记与图片导出交互 |
| `media_tool/frame_store.py` | 标记及查看位置持久化 |
| `media_tool/widgets.py` | 共用视频画面控件 |
| `media_tool/media.py` | 视频信息、解码、FFmpeg 处理 |
| `media_tool/rendering.py` | 视频帧转 Qt 图片 |
| `media_tool/exports.py` | 已标记帧图片导出 |
| `media_tool/workers.py` | 后台任务 |
| `media_tool/demo.py` | 演示视频生成 |
